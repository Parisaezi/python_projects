# Number Guesser Game Project 🎯
## 📖 Description:
This project is a game where the user must guess a number between 1 and 100. The program generates a random number. Then, the user enters a guess. For each incorrect attempt, the user receives a hint. In addition, their attempts increase by 1 for every wrong guess.

## 🕹️ Example Gameplay:
- Guess a number between 1 and 100: 55
- Your guess is too low.
- Guess a number between 1 and 100: 76
- Congratulation. Your guess is just right. You attempted: 1

## ▶️How to run:
then run `python main.py`
